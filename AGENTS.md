# AGENTS.md

## Repository Rules

- Work directly in this repository and on the current branch.
- Do not create Git worktrees for any task in this repo.
- Execute all changes here directly instead of using a separate worktree or detached copy.
- If you create or use a temporary script for a task, delete it immediately after use.
- Keep the codebase clean. Remove temporary artifacts, throwaway files, and no-longer-needed helper files after finishing work.
- If you create an important Markdown document, place it in the `docs/` folder unless there is a stronger existing convention for that file.
- Avoid writing files that exceed 500 lines when reasonably possible.
- If you encounter a file that is over 500 lines and you need to work in it, refactor or split it when practical instead of making it grow further.
- Preserve existing project conventions unless they conflict with the rules above.
